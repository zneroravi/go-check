# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please follow these steps:

1. **Do not** open a public issue on GitHub
2. Email security details to [security@example.com] or use the GitHub Security Advisory "Private vulnerability reporting" feature
3. Include the following information in your report:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will acknowledge receipt of your report within 3 business days and provide a more detailed response within 7 business days indicating the next steps.

Please do not disclose the vulnerability publicly until we have addressed it.
