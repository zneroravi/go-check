# Changelog

All notable changes to this project will be documented in this file. This format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added

- Initial release of URL shortening API
- Express.js server with Helmet, CORS, and Morgan middleware
- SQLite database integration using better-sqlite3
- URL creation and redirection endpoints
- Health check endpoint
- Global error handling middleware
- Environment configuration with dotenv
- Structured logging
- Input validation and AppError class
- TypeScript project setup with strict mode
- Vitest test suite with Supertest integration
- Docker support with multi-stage builds
